# FieldFlow

Run the repository root setup, then open `/leads`. Source: `app/leads.py`.

## 60-second demonstration

1. Inspect the funnel and stage board.
2. Create Jamie Taylor's three-room move-out inquiry using a synthetic `.test` email.
3. Inspect the USD 295 quote and approve it.
4. Try `Tomorrow · 09:00`; the existing booking prevents double-booking.
5. Select `Tomorrow · 13:00`; inspect calendar/confirmation receipts.
6. Advance the demo clock to show reminders; complete the job to record a review request.

Prices, contacts and appointments are fixtures. Service classification and quote rules are deterministic. All provider messages remain local. See [CASE-STUDY.md](CASE-STUDY.md), [architecture.mmd](architecture.mmd) and `assets/`.
