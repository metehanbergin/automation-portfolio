# StayOps

Run the repository root setup, then open `/guests`. Source: `app/guests.py`.

## 75-second demonstration

1. Inspect the Wi-Fi replies: Seabrook and Orchard have different fictional credentials.
2. Select the smoke message: urgent alert and safe standby, not an invented solution.
3. Respond to the unknown luggage question with: `Luggage may be stored in the locked lobby cupboard until 16:00. Ask the host to open it when you return.`
4. Leave the knowledge proposal checkbox enabled. Open Knowledge base and review the draft.
5. Approve the entry separately.
6. Send the same question for RES-101: `Can we store luggage after checkout?`
7. Inspect the automatic reply and source. The same fact remains unavailable to RES-102.

The knowledge is synthetic. Local retrieval and heuristic language routing run without paid APIs. The optional model adapter prepares drafts only and has not been live-model tested. See [CASE-STUDY.md](CASE-STUDY.md), [architecture.mmd](architecture.mmd) and `assets/`.
